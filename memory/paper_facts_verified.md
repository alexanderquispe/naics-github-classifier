Verified from `memory/transformer_based_repository_classification.pdf` (slides dated 2026-05-22) and direct inspection of `data/output/train_data_gpt_ab8score.parquet`:

**Title:** "Industry Classification of GitHub Repositories Using the North American Industry Classification System (NAICS)"

**Authors / emails:** Kevin Xu (khxu@github.com), Alexander Quispe (alexanderquispe@github.com). Author order on the title slide: Xu, Quispe.

**Pipeline figures (from the slides):**
- USA stage: 511k repos → 10,983 semantic-match candidates → ~2,529 GPT-validated (score ≥ 8).
  ⚠ CORRECTION 2026-06-10: the slide's "BGE-large-en-v1.5, top 20 per
  subindustry" is inaccurate — the executed Colab cells used
  **bge-large-en (v1)** on README-only text with dynamic
  k = max(20, ceil(400/n)). See [[dataset-lineage]] and PIPELINE.md
  funnel section. The 10,983 and 2,529 counts themselves are verified
  correct (EU 10,531→2,039, AU 9,664→2,021; original total 31,178).
- Multi-region expansion: EU + AU added for 6,588 total — but EU/AU labels were generated by DeepSeek, which is OUT OF SCOPE per `paper_decisions.md`.
- Downstream: RoBERTa-Base fine-tuned, 70/10/20 split on 6,588.
- Missing sector: NAICS 55 (Management of Companies and Enterprises) — no data.

**Released artifact on disk (GPT-only):**
- File: `data/output/train_data_gpt_ab8score.parquet`
- Rows: 2,538 (slide 9 said ~2,529 — close, minor difference is normal post-filter)
- Region: **USA only** (sector counts match slide 11 exactly).
- Columns: `nwo, name_repo, description, topics, readme_content, code, match, score, rationale, repo_url`
- All `match == "Yes"`. Score distribution: 8→330, 9→2,060, 10→148. NAICS 55 absent.

**Human gold labels:** Alexander's research assistants have already done a manual check; the labeling sheet is at https://docs.google.com/spreadsheets/d/1r7fi6DBIeMsVXE7XfOJNZZt8fqwU8TgD/edit (I do not have access from this environment; ask Alexander for an export or a CSV path).

**Why this matters:** The user said the released training data "includes USA, EU, AU" — but on disk the GPT-labeled file is USA-only. The discrepancy is because EU+AU labels are DeepSeek, which the paper excludes. Region scope for the paper is therefore USA-only unless GPT is run on EU+AU first.

**How to apply:** Treat USA-only as the default for Phase 0 unless the user explicitly says to run GPT on EU+AU. If they want all three regions in the paper, that's a budget + timeline decision that must be made before writing.
