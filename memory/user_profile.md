Alexander Quispe is a researcher at GitHub and is also affiliated with Caltech. Email: alexander.quispe@pucp.edu.pe. He is working with colleague Kevin Xu on building a training dataset that maps GitHub repositories to NAICS industry sectors. The eventual downstream artifact is a fine-tuned ModernBERT classifier (`naics-github-train`). He cares about cost-aware design (limited budget), reproducibility, and matching the behavior of an original Colab notebook when in doubt. See also [[collaborator-kevin-xu]] and [[project-goal]].
